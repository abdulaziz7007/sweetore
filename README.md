# Sweetora — Premium Dessert E-Commerce

Next.js 15 + TypeScript + Tailwind CSS + Framer Motion + Lucide React.

## Ishga tushirish
```bash
npm install
npm run dev
```

Build tekshiruvi:
```bash
npm run build
```

## Til tizimi (i18n)
Sayt ichida **UZ / RU** til almashtirgich mavjud. Tanlangan til `localStorage` orqali saqlanadi va sahifalar bo‘ylab ishlaydi. Mahsulot nomi, kategoriyasi va asosiy UI matnlari ham tarjima qilinadi.

## Funksiyalar
- 12 ta route
- 20+ mahsulot
- Qidiruv, kategoriya va sorting
- Mahsulot detail sahifasi
- Savatcha + localStorage
- Sevimlilar + localStorage
- Checkout va validation
- Login / Register / Profile UI
- Orders / About / Contact
- Responsive desktop/tablet/mobile
- Framer Motion-ready premium UI
- UZ/RU i18n

Bu frontend/demo loyiha. Real backend, Google Auth va to‘lov provayderi ulanmagan.
